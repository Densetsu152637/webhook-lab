# Security policy

The runtime is unfinished. There are no supported production releases. Use this project for learning with synthetic data and endpoints you control.

Report suspected vulnerabilities privately through [GitHub private vulnerability reporting](https://github.com/Densetsu152637/webhook-lab/security/advisories/new). Include the affected revision, prerequisites, sanitized reproduction, and impact. Do not put credentials, private webhook payloads, or exploit details in a public issue. If private reporting is unavailable, open a public issue requesting a private reporting channel without sensitive details.

See [security controls and maintenance](docs/security.md) for the audit scope, trust boundaries, and limitations. No response-time commitment or security certification is implied.
